| Version | Supported          |

## Reporting a Vulnerability

If you discover a security vulnerability in Jarvis Video Studio, please do not open a public issue.
Instead, report it via GitHub Private Vulnerability Reporting or contact the maintainer directly at:

- GitHub: [@Sonness1304](https://github.com/Sonness1304)
- Email: `luongson8648@gmail.com`

We will acknowledge receipt within 48 hours and work on a remediation promptly.
